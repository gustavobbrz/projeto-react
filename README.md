# 🍁 Pro-League Arenas 🍁 - HaxBall Server Website

Este é o site oficial do servidor **Pro-League Arenas**, criado para **HaxBall**. O projeto foi desenvolvido com **Vite** e **React** para estudar e aplicar meus conhecimentos em desenvolvimento web.

## 🚀 Tecnologias Utilizadas

- **React**: Biblioteca JavaScript para criação de interfaces de usuário.
- **Vite**: Ferramenta de construção e bundling super-rápida para projetos React.
- **Node.js**: Ambiente de execução JavaScript utilizado no backend.
- **npm**: Gerenciador de pacotes para instalar as dependências do projeto.
- **ChatGPT**: Utilizado para me ajudar a aprimorar funcionalidades e melhorar o desenvolvimento de algumas partes do site.
- **CSS**: Para estilizar o layout e tornar o site visualmente atraente.

## 🌟 Funcionalidades

- **Salas Online**: Visualização de salas de HaxBall ativas com informações de número de jogadores e status.
- **Integração com Discord**: Facilita a comunicação entre os jogadores da sala através do Discord.
- **Sistema de VIP**: Compra de VIP para acesso a funcionalidades exclusivas.
- **Regras do Servidor**: Página dedicada com as regras de jogo do servidor.
- **Suporte**: Sistema dedicado de suporte para ajudar os jogadores com dúvidas.

## 📜 Como Rodar o Projeto

Para rodar o projeto localmente, siga os seguintes passos:

### 1. Clone o repositório:

```bash
git clone https://github.com/gustavobbrz/projeto-react.git

2. Navegue até o diretório do projeto:
cd projeto-react

3. Instale as dependências:
npm install

4. Inicie o servidor de desenvolvimento:
npm run dev

O projeto estará disponível em http://localhost:3000.
